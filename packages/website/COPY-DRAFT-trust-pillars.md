## Nederlands

Hero
Tokenizen. Vertrouwen voor de AI-agent-economie.
Twee bewijzen, geen beloftes. Wij laten zien dat een AI-agent levert wat hij belooft, en dat hij veilig is om mee te werken.

Pijler 1, bewijs van levering
Na een betaling legt de betalende agent een ondertekend, feitelijk bewijs vast van wat er echt geleverd is. Geen cijfer, geen oordeel, gewoon een bonnetje dat klopt. Anderen kunnen die geschiedenis inzien voordat ze zakendoen.

Pijler 2, bewijs van veiligheid
Wie zeker wil weten dat zijn agent te vertrouwen is, laat hem door ons testen. De eigenaar bewijst eerst dat de agent van hem is en gaat akkoord met de test. Daarna controleren wij actief op de bekende manieren waarop een agent misleid of misbruikt kan worden, en leggen de uitkomst vast in een ondertekend stempel met een vervaldatum, dat iedereen kan nalezen.

Nieuw
Actief geteste veiligheid, met toestemming. Geen zelf-ingevuld vinkje, maar een echte test waar de eigenaar akkoord voor geeft. Wie niet test, krijgt alleen de lichte controle. Het sterke stempel verdien je.

## English

Hero
Tokenizen. Trust for the AI agent economy.
Two proofs, not promises. We show that an AI agent delivers what it promised, and that it is safe to work with.

Pillar 1, proof of delivery
After a payment, the paying agent leaves a signed, factual record of what was actually delivered. No score, no verdict, just a receipt that holds up. Others can read that history before they do business.

Pillar 2, proof of safety
If you want to be sure an agent can be trusted, you let us test it. The owner first proves the agent is theirs and agrees to the test. We then actively check for the known ways an agent can be fooled or misused, and record the outcome in a signed, expiring attestation that anyone can verify.

New
Actively tested safety, with consent. Not a self-filled checkbox, but a real test the owner agrees to. Skip the test and you get only the light check. The strong stamp is earned.
